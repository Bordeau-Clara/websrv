Bienvenue sur webserv42 !

Ce serveur est un projet développé dans le cadre de l'École 42. Il prend en charge les requêtes HTTP/1.1 et est optimisé pour la performance.

⚡ Performant

Conçu pour gérer plusieurs requêtes simultanées avec une latence minimale.

🛠️ Configurable

Personnalise les routes, les ports et les réponses selon tes besoins.

🔒 Sécurisé

Gestion des en-têtes modernes comme Sec-Fetch-* et Upgrade-Insecure-Requests.

Comment tester ?

Tu peux tester ce serveur en envoyant des requêtes HTTP à http://localhost:8002.

Exemple avec curl :

curl -v http://localhost:8002

Prochaines étapes

Ce projet est en développement actif. Voici ce qui est prévu :

  • Support des méthodes HTTP (GET, POST, DELETE)
  • Gestion des fichiers statiques
  • Support des CGI
