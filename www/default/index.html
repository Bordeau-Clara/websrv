About the Project

WebServ is a comprehensive web server implementation developed as part of the École 42 common core curriculum. This project demonstrates advanced systems programming concepts including network programming, I/O multiplexing, HTTP protocol implementation, and server architecture design.

Built entirely in C++98, WebServ handles multiple simultaneous connections efficiently using non-blocking sockets and the epoll() system call. The server supports virtual hosting, custom error pages, file uploads, cookie management, and CGI script execution.

This implementation serves as both a learning experience and a practical demonstration of low-level network programming principles, providing deep insight into how web servers operate under the hood.
